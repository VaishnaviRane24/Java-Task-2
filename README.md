**Java Internship Task 2**
---
**Variables, Data Types and Console Input Application**
---
**Overview**
---
This project is a simple Java console application created as part of **Java Developer Internship – Task 2**.
The goal of this task is to understand Java variables, primitive data types, user input handling, type casting, and variable scope, along with clean and readable code.

---
**Features Implemented**
---
. Declaration of **all Java primitive data types** with comments explaining memory usage

. Usage of **Scanner class** to take user input from the console

. **Input validation** using `hasNextInt()` to handle invalid inputs gracefully

. Implementation of **basic arithmetic operations**:

                                    . Addition

                                    . Subtraction

                                    . Multiplication

                                    . Division (with divide by zero handling)

. Demonstration of **type casting**:

                                    . Widening casting (int to double)

                                    . Narrowing casting (double to int)

. Clear demonstration of:

                                    . Local variables

                                    . Instance variables

                                    . Static variables

. Formatted output using `System.out.printf()`

---
**Technologies Used**
---
. **Language**: Java

. **IDE / Tools**:

                                    . Terminal (javac & java)

                                    . Can also be run on IntelliJ IDEA, Eclipse, or VS Code

---
**How to Run the Program**
---
1. Open terminal or command prompt

2. Navigate to the project directory

3. Compile the program:

                                   `javac Variable.java`


4. Run the program:

                                  `java Variable`


5. Enter two integer values when prompted
